# Project Overview

This project investigates whether hierarchical labels generated by a
locally hosted Large Language Model (LLM) can be used as an effective
substitute for manually annotated labels when training supervised news
article classifiers.

The project extends beyond a traditional text-classification pipeline by
comparing two document representations:

-   TF-IDF feature vectors
-   Sentence-BERT semantic embeddings

Hierarchical LLM-generated labels are compared against the original CNN
labels across multiple classifiers and evaluation metrics. Additional
analyses include exploratory data analysis (EDA), latent topic modelling
(LDA), semantic nearest-neighbour analysis, and a direct comparison of
representation-learning approaches.

# Methodology

## Hierarchical LLM Label Generation

The LLM predicts labels in two stages:

1.  Predict a **Category**
2.  Predict a valid **Section** constrained by the selected Category

This prevents invalid Category--Section combinations and mirrors the
editorial hierarchy of the original CNN dataset.

## Exploratory Data Analysis

The EDA stage summarizes:

-   Missing values
-   Class distributions
-   Duplicate records
-   Text statistics
-   Dataset quality

## Topic Modelling

Latent Dirichlet Allocation (LDA) is used to examine latent themes
within the corpus and compare discovered topics with the original
editorial categories.

## Text Representations

### TF-IDF

Traditional sparse lexical representation used with:

-   Logistic Regression
-   Linear SVM
-   Multinomial Naive Bayes

### Sentence-BERT

Dense semantic embeddings generated using:

-   all-MiniLM-L6-v2

Embedding classifiers include:

-   Logistic Regression
-   Linear SVM
-   Random Forest
-   XGBoost
-   Small Neural Network

# Experimental Design

Four prediction tasks are evaluated.

  Representation   Training Labels   Testing Labels
  ---------------- ----------------- ----------------
  TF-IDF           Original CNN      Original CNN
  TF-IDF           LLM               Original CNN
  Sentence-BERT    Original CNN      Original CNN
  Sentence-BERT    LLM               Original CNN

Using the same held-out test set ensures that observed differences arise
from the representation or label source rather than differences in
evaluation data.
